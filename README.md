# Riesgos Biomecánicos en la cocina

Presentación web animada con identidad gastronómica, pensada como apoyo visual para una exposición oral.

## Cómo usarla

Abre `index.html` en el navegador (o la versión publicada en GitHub Pages).

| Acción | Tecla |
| --- | --- |
| Avanzar (paso a paso) | → · Espacio · Enter · clic |
| Retroceder | ← · clic en el borde izquierdo |
| Notas para la exposición | N |
| Pantalla completa | F |

Cada diapositiva revela sus ideas en pasos, para que el contenido aparezca al ritmo de la explicación.

## Publicar en GitHub Pages

Settings → Pages → *Deploy from a branch* → elige esta rama y la carpeta `/ (root)`.
